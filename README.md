# Toyota Full-Stack Web Application 🚗

A comprehensive full-stack web application built for Toyota Motor Corporation, demonstrating modern web development practices using ASP.NET Core MVC.

## 🔗 Live Demo
[Check out the live project here!](https://toyota-demo-app.onrender.com)

## 🛠️ Technologies Used
* **Backend:** ASP.NET Core MVC (.NET 10.0), C# 13.0
* **Database:** SQLite with Entity Framework Core (ORM)
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla ES6+)
* **Deployment:** Docker & Render

## ✨ Key Features
* **MVC Architecture:** Clean separation of concerns with 14 controllers, 7+ models, and 25+ views.
* **RESTful API:** 5 API endpoints supporting GET, POST, PUT, and DELETE operations.
* **Dynamic Frontend:** API consumed by JavaScript Fetch on the frontend to dynamically load vehicles and offers without page reloads.
* **Database Integration:** Fully relational SQLite database with 9 tables, EF Core migrations, and pre-seeded data.
* **Authentication:** Session-based secure authentication system for Admin and regular User accounts.
* **Admin Dashboard:** Complete Admin panel with full CRUD operations for managing vehicles, engineers, and managers.
* **Interactive UI:** Dynamic JS filtering, Build & Price tool, and live cart checkout flow.
